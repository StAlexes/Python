Электронная структура изделий (ЭСИ)
  Внимание

Данный раздел предназначен для описания работы с устаревшим механизмом, основанном на взаимодействии справочника ЭСИ со связанными справочниками (Документы, Материалы, Электронные компоненты и т.д.).
На текущий момент работа с объектами справочника ЭСИ не отличается от работы с другими справочниками системы. Подробнее о работе с объектами: «Создание, редактирование объектов»
Команды для работы с ЭСИ

ЭСИ.Подключить((объект)[, (родительский объект)]) - подключает объект к ЭСИ

C#
Копировать 
Объект объектЭси = ЭСИ.Подключить(ТекущийОбъект);

 

Объект.СвязанныйОбъект ["Связанный объект"] - возвращает связанный объект для объекта ЭСИ

C#
Копировать 
Объект связанныйОбъект = объектЭси.СвязанныйОбъект["Связанный объект"];

 

Объект.СвязанныйОбъект ["Объект ЭСИ"] - возвращает объект ЭСИ, связанный с данным объектом

C#
Копировать 
Объект объектЭси = ТекущийОбъект.СвязанныйОбъект["Объект ЭСИ"];

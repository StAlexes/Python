Копирование объектов

Объект.ПолнаяКопия([копируемыеСвязи]) - создает полную копию объекта и сохраняет ее на сервере.
Копирование объектов по связям зависит от того, передаются ли эти связи (названия связей или их Guid'ы) в метод. Если связь не передается в качестве аргумента, то:

  • связи типа "Один с одним" и "Один со списком" игнорируются;

  • копия основного объекта подключается по связям типа "Список со списком" и "Список с одним"

Если связь передается в качестве аргумента метода, то вне зависимости от типа связи, для связанных объектов создаются копии и они подключаются к созданной копии основного объекта.

C#
Копировать 
Объект поручение = НайтиОбъект("Поручения", "Наименование", "Поручение 1");
Объект копияПоручения = поручение.ПолнаяКопия("Связанные материалы");

 

Объект.Копия() - возвращает созданную копию объекта в режиме редактирования (несохраненную на сервере).

Объект.Копия("(Тип)"[, "(РодительскийОбъект) ", "(ПропущенныеПараметры)"]) - возвращает созданную копию объекта заданного типа в режиме редактирования (несохраненную на сервере). Если связи объекта не указаны в списке 'ПропущенныеПараметры', то:

  • связи типа "Один с одним" и "Один со списком" игнорируются;

  • копия целевого объекта подключается по связям типа "Список со списком" и "Список с одним"

C#
Копировать 
Объект поручение = НайтиОбъект("Поручения", "Наименование", "Поручение 1");
// Создаем копию без указания типа (если тип не указан, то тип копии будет как у целевого объекта) и без родительского объекта
Объект копияПоручения = поручение.Копия(null, null, "Связанные материалы", "Исполнитель");
копияПоручения.Сохранить();

Обработка событий

Если действие в системе направлено на объект или подключение в целом, то для обработки события достаточно информации о текущем объекте или подключении, которую можно получить из контекста выполнения макроса MacroContext:

C#
Копировать 
ReferenceObject currentObject = Context.ReferenceObject; // Получаем текущий объект
ComplexHierarchyLink hierarchyLink = Context.HierarchyLink; // Получаем текущее подключение

К таким события относятся: «Удаление объекта», «Создание объекта», «Сохранение объекта», «Завершение сохранения объекта», «Создание подключения», «Удаление подключения».

Для ряда событий контекст выполнения макроса предоставляет возможность получения аргументов событий через свойство ModelChangedArgs.
Аргументы событий позволяют получить данные, связанные с инициированными событиями.

C#
Копировать 
ModelEventArgs modelEventArgs = Context.ModelChangedArgs; // Получаем аргументы события изменения в модели

Класс ModelEventArgs является базовым типом для всех классов аргументов событий. В зависимости от обрабатываемого события необходимо привести свойство ModelChangedArgs к нужному типу для получения аргументов.
Типы и аргументы, соответствующие конкретному событию, описаны далее

  Примечание

Незавершенные действия («Удаление объекта», «Сохранение объекта» и т.д.) можно отменить. Для этого необходимо вызвать команду макроязыка Отменить() или сгенерировать соответствующее исключение: throw new MacroException(true).

Пример с отменой действия: «Изменение связи объекта»
Аргументы событий «Изменение параметра объекта» и «Завершение изменения параметра объекта»

ObjectParameterChangingEventArgs - аргументы события изменения параметра объекта справочника

ObjectParameterChangedEventArgs - аргументы события завершения изменения параметра объекта справочника

ObjectParameterChangedEventArgs и ObjectParameterChangingEventArgs предоставляют информацию об изменяемом параметре через свойство Parameter, а также позволяют узнать предыдущее значение параметра через свойство OldValue и новое значение через свойство NewValue

Пример работы с данными аргументами событий: «Завершение изменения параметра объекта»

Аргументы событий «Изменение связи объекта» и «Завершение изменения связи объекта»

ObjectLinkChangingEventArgs - аргументы события изменения связи объекта справочника

ObjectLinkChangedEventArgs - аргументы события завершения изменения связи объекта справочника

ObjectLinkChangedEventArgs и ObjectLinkChangingEventArgs предоставляют информацию об изменяемой связи через свойство Link, а также позволяют узнать какой объект был подключен через свойство AddedObject или отключен - RemovedObject

Пример работы с данными аргументами событий: «Изменение связи объекта»

Аргументы событий «Изменение стадии объекта» и «Завершение изменения стадии объекта»

ObjectStageChangingEventArgs - аргументы события изменения стадии объекта справочника

ObjectStageChangedEventArgs - аргументы события завершения изменения стадии объекта справочника

ObjectStageChangedEventArgs и ObjectStageChangingEventArgs позволяют получить информацию о предыдущей стадии через свойство OldStage и о новой стадиии через свойство NewStage

Аргументы события «Изменение порядкового номера объекта»

ObjectOrderChangedEventArgs - аргументы события изменения порядкового номера объекта справочника

ObjectOrderChangedEventArgs позволяет получить информацию о старом значении номера через свойство OldOrder и о новом значении номера через свойство NewOrder

Пример работы с данными аргументами событий: «Изменение порядкового номера объекта»

Аргументы событий «Завершение применения изменений» и «Применение изменений»

ObjectDesktopCheckingInEventArgs - аргументы события применения изменений объекта справочника

ObjectDesktopCheckInEventArgs - аргументы события завершения применения изменений объекта справочника

ObjectDesktopCheckingInEventArgs и ObjectDesktopCheckInEventArgs позволяют получить описание операции рабочего стола через свойство Operation. Описание операции рабочего стола содержит тип операции (Type); список объектов, для которых выполняется операция (Items); комментарий (Comment); флаг, отвечающий за необходимость оставить объект в работе (KeepCheckedOut)

Пример работы с данными аргументами событий: «Операции с рабочим столом»

Аргументы события «Изменение подписи объекта»

ObjectSignatureChangedEventArgs - аргументы события изменения подписи объекта справочника

ObjectSignatureChangedEventArgs позволяет получить подпись через свойство Signature и тип операции, производимой с подписью (добавление, удаление, редактирование, обновление), при помощи свойства OperationType

Пример: «Изменение подписи»

Аргументы события сервера

ServerEventArgs - аргументы события сервера

ServerEventArgs позволяет получить обработчик события через свойство ServerEventHandler

Пример: «Событие сервера»

Контекст выполнения макроса

Контекст выполнения макроса (MacroContext) представляет собой набор свойств, определяющих окружение, в котором выполняется макрос, а также методов, позволяющих взаимодействовать с данным окружением

Свойства и методы контекста выполнения макроса

Connection - возвращает текущее соединение с сервером. Подробнее о соединении с сервером: «Соединение с сервером приложений»

Reference - возвращает текущий справочник

ConfigurationSettings - возвращает настройки конфигурации текущего справочника

C#
Копировать 
var currentConfigurationSettings = Context.ConfigurationSettings; // Получаем настройки конфигурации текущего справочника

var newConfigurationSettings = new ConfigurationSettings(currentConfigurationSettings)
{
    Date = "Сегодня",
    ApplyDate = true
}; // Создаем новые настройки на основе текущих

 

ReferenceObject - возвращает текущий объект

HierarchyLink - возвращает текущее подключение

C#
Копировать 
ReferenceObject currentObject = Context.ReferenceObject; // Получаем текущий объект
ComplexHierarchyLink hierarchyLink = Context.HierarchyLink; // Получаем текущее подключение

 

ModelChangedArgs - возвращает аргументы события изменения в модели. Подробнее об аргументах событий: «Обработка событий»

IsAdministrator - возвращает значение, указывающее, является ли текущий пользователь администратором системы

CancellingChanges - возвращает значение, указывающее, выполняется ли отмена изменений при завершении редактирования свойств текущего объекта. Подробнее отмене изменений: «Завершение редактирования свойств объекта»

ShowMessage(caption, text[, args]) - показывает сообщение

C#
Копировать 
Context.ShowMessage("Результат", "Объекты успешно сохранены");

 

ShowQuestion(text) - показывает сообщение с иконкой "Вопрос" и вариантами Да/Нет

C#
Копировать 
if (Context.ShowQuestion("Внимание", "Объекты будут удалены, продолжить?"))
{
    // ...
}

 

RunOnUIThread(action) - выполняет указанный метод в UI-потоке. Макросы выполняются в рабочем потоке, поэтому взаимодействие с UI необходимо передать в данный метод. Подробнее о выполнении в UI-потоке: «Программное открытие вкладок»

ShowClassObjectSelectionDialog(referenceName[, caption]) - отображает диалог выбора типа объекта справочника

C#
Копировать 
// Показываем диалог выбора типа
TFlex.DOCs.Model.Classes.ClassObject classObject = Context.ShowClassObjectSelectionDialog("Группы и пользователи", "Выбор типа");

if (classObject is not null)
{
    // ...
}

 

CloseDialog(saveChanges[, showConfirmationOnCancel]) - закрывает диалог свойств объекта с возможностями сохранения изменений и отображения подтверждения при отмене

Руководство по T-FLEX DOCs Open API

Регистрация справочников во внешнем приложении

Приложение (плагин) - это библиотека классов Microsoft .NET Framework, реализующая определенную прикладную задачу с использованием API T-FLEX DOCs.
Некоторые классы, сгенерированные для поставочных справочников T-FLEX DOCs ("Процедуры", "Управление проектами", "Схемы" и т.д.), определены в отдельных плагинах. При открытии клиента T-FLEX DOCs система автоматически регистрирует эти классы (описание процесса регистрации можно найти в директории с установленным клиентом T-FLEX DOCs: "..\Примеры использования API\Graphs\Описание.docx").
Взаимодействие с этими классами во внешнем приложении также требует их регистрации. В противном случае, при попытке обращения к ним, система выдаст ошибку следующего вида: "Объект "класс плагина" не может использоваться для работы с группой "группа параметров", так как для работы с ней зарегистрирован объект "базовый класс для работы с группой параметров".
Более подробную информацию о работе с API T-FLEX DOCs из внешнего приложения можно найти в разделе: «Соединение с сервером из внешнего приложения»

using System;
using System.Linq;
using TFlex.DOCs.Common.Extensions;
using TFlex.DOCs.Model;
using TFlex.DOCs.Model.Plugins.Applications;
using TFlex.DOCs.Model.References.Nomenclature;
using TFlex.DOCs.Model.References.Processes;
using TFlex.PdmFramework.Resolve;

namespace RegisterSpecialReferenceInApp
{
    class Program
    {
        static void Main(string[] args)
        {
            AssemblyResolver.Instance.AddDirectory(@"C:\Program Files (x86)\T-FLEX DOCs 18\Program");
            MainCore();
        }

        private static void MainCore()
        {
            using var serverConnection = ServerConnection.Open("Администратор", String.Empty, "localhost"); // Подключаемся к серверу

            if (!serverConnection.IsConnected)
                throw new InvalidOperationException("Подключение к серверу отсутствует");

            // Можем зарегистрировать классы конкретного плагина:
            // new TFlex.DOCs.Model.Processes.PluginLibrary().RegisterPlugin(); 
            // Можем получить все системные плагины и зарегистрировать необходимые:
            var systemApplications = ApplicationsManager.GetSystemApplicationsModels(); // Получаем системные плагины
            var applicationsManager = new ApplicationsManager(serverConnection); // Создаем менеджер плагинов
            // Загружаем плагины, тем самым регистрируем классы
            applicationsManager.LoadApplications(e => Console.WriteLine("Ошибка при загрузке плагина: " + e.Message), systemApplications.Select(p => p.Guid));

            var nomenclatureObject = new NomenclatureReference(serverConnection).Find(Guid.Empty); // Находим объект ЭСИ
            var runningProcesses = ProcessesReference.GetRunningProcessesByObject(nomenclatureObject); // Находим работающие процессы, в которых участвует объект ЭСИ
            runningProcesses.ForEach(p => p.Terminate("Прерывание")); // Прерываем процессы
        }
    }
}

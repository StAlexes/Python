Руководство по T-FLEX DOCs Open API

Введение

Настоящее руководство описывает структуру, классы и методы программного интерфейса (API) системы T-FLEX DOCs. Описываемый программный интерфейс используется при разработке макросов, модулей расширения функциональности (приложений) и внешних приложений, использующих функциональность T-FLEX DOCs.

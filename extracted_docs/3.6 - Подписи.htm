Подписи
Команды для работы с подписями.

Объект.Подписи - Возвращает список подписей объекта.

C#
Копировать 
foreach (Подпись подписьОбъекта in ТекущийОбъект.Подписи)
{
    // ...
}

 

Объект.ДобавитьПодпись("(Тип подписи)", (пользователь)) - Добавляет подпись к объекту. Возвращает True, если подпись успешно добавлена, иначе возвращает False.

C#
Копировать 
ТекущийОбъект.ДобавитьПодпись("Разраб.", ТекущийПользователь);

 

Объект.Подписать("(Тип подписи)", [(пользователь)], "(резолюция)") - Подписывает объект и добавляет резолюцию к объекту. Возвращает True, если объект успешно подписан, иначе возвращает False.

C#
Копировать 
ТекущийОбъект.Подписать("Утв.", "Утверждаю.");

 

Подпись.ТипПодписи - Возвращает наименование типа подписи.

Подпись.Пользователь - Возвращает объект пользователя подписи.

Подпись.ДатаПодписи - Возвращает дату подписи, если объект был подписан, иначе возвращает null.

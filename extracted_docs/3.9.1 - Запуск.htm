Запуск
Команды для запуска бизнес-процессов

БизнесПроцессы.Запустить(наименование[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты]) - запускает бизнес-процесс по наименованию

БизнесПроцессы.Запустить(наименование, объект[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты]) - запускает бизнес-процесс по наименованию с возможностью подключения объекта

БизнесПроцессы.Запустить(наименование, объекты[, переменные, показывать диалог, шаблон переменных, начало, вспомогательныеОбъекты]) - запускает бизнес-процесс по наименованию с возможностью подключения объектов

Пример запуска бизнес-процесса
C#
Копировать 
Объекты объектыПоБП = НайтиОбъекты("Документы", "[Тип] = 'Изделие'"); // Находим объекты, которые подключим к БП

var переменные = new Dictionary<string, object>  // Список из пар "Наименование переменной" + "значение"
{
    {"Переменная1", 5},
    {"Переменная2", "текстовое значение"}
};

// Запускаем бизнес-процесс
БизнесПроцессы.Запустить(
    "Тестовый бизнес-процесс", // Наименование бизнес-процесса
    объектыПоБП, // Идущие по процессу объекты
    переменные, // Список наименований и значений переменных
    false); // Скрываем мастер запуска
Команды для запуска линейных бизнес-процессов

БизнесПроцессы.ЗапуститьЛинейныйПроцесс() - запускает линейный бизнес-процесс

БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Объект) - запускает линейный бизнес-процесс с возможностью подключения объекта

БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Объекты) - запускает линейный бизнес-процесс с возможностью подключения объектов

БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Прототип[, показывать диалог]) - запускает линейный бизнес-процесс по прототипу

БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Прототип, объект[, показывать диалог]) - запускает линейный бизнес-процесс по прототипу с возможностью подключения объекта

БизнесПроцессы.ЗапуститьЛинейныйПроцесс(Прототип, объекты[, показывать диалог]) - запускает линейный бизнес-процесс по прототипу с возможностью подключения объектов

Пример запуска линейного бизнес-процесса
C#
Копировать 
Объект документ = НайтиОбъект("Документы", "[ID] = '1'"); // Находим объект, который подключим к линейному БП

// Запускаем линейный бизнес-процесс по прототипу с отображением диалога
БизнесПроцессы.ЗапуститьЛинейныйПроцесс("Прототип", документ, true);

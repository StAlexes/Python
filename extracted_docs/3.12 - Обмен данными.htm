Обмен данными

Модуль обмена данными T-FLEX DOCs позволяет осуществлять экспорт и импорт (получение, создание, изменение и удаление) объектов справочников системы.
Доступ к модулю можно получить непосредственно из макроса:

C#
Копировать 
Объекты экспортируемыеДокументы = НайтиОбъекты("Документы", "[Тип] = 'Изделие'"); // Находим объекты, которые будут экспортированы
ОбменДанными.ЭкспортироватьОбъекты("Правило обмена", экспортируемыеДокументы, false); // Экспортируем объекты по указанному правилу без отображения диалога

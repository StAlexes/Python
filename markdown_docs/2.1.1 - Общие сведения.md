Макрос - это программа, содержащая набор инструкций для выполнения определенной задачи.
В системе T-FLEX DOCs макросы хранятся в виде исходных кодов на языке C#, которые компилируются системой
перед использованием. Работа с макросами в T-FLEX DOCs осуществляется с помощью встроенного редактора кода.

В системе T-FLEX DOCs существует два основных типа макросов:

- Макрос - упрощенный макрос, использующий команды макроязыка
- Макрос C# - макрос, использующий все возможности языка C# и API T-FLEX DOCs
Упрощенный макрос

Упрощенный макрос представляет собой набор инструкций макроязыка.
Макроязык T-FLEX DOCs - специально разработанный набор команд для выполнения базовых операций над
объектами системы. Упрощенные макросы, как правило, используются для реализации простых и коротких алгоритмов.

Макрос C#

Макрос C# представляет собой программу на языке C#. В макросах этого типа возможно создание
классов и подключение внешних библиотек, что позволяет использовать все возможности API T-FLEX DOCs
и разрабатывать достаточно сложные решения.

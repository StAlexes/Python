Бизнес-процесс в T-FLEX DOCs выполняется по заранее созданной и настроенной бизнес-процедуре.
Бизнес-процедура T-FLEX DOCs представляет собой алгоритм, отражающий последовательность действий работников при выполнении типовой
повторяющейся процедуры в организации. Данный алгоритм представлен в виде блок-схемы, отдельные структурные элементы которой называются состояниями.
Состояния бывают различных типов, например, таких как "Работа", "Согласование", "Рассылка уведомления", каждый из которых имеет свои параметры.
Информация о запуск БП представлена в разделе «Запуск БП»
Взаимодействие с объектами в рамках БП описано в разделе «Работа с объектами»

Базовые возможности

ТекущийПроцесс
- возвращает текущий процесс

```csharp
Процесс процесс = ТекущийПроцесс;
```

АвторБизнесПроцесса
- возвращает автора бизнес-процесса

```csharp
Пользователь авторБизнесПроцесса = АвторБизнесПроцесса;
```

`СоздатьОшибку(сообщение[, имя или Guid состояния типа 'Исключение'])`
- создает ошибку с заданным сообщением и с возможностью перехода в указанное состояние типа «Исключение»

```csharp
СоздатьОшибку("Возникла ошибка при согласовании отпуска", "Исключение");
```

`СоздатьОшибку(сообщение, исключение[, имя или Guid состояния типа 'Исключение'])`
- создает ошибку с заданным сообщением, исключением и с возможностью перехода в указанное состояние типа «Исключение»

```csharp
try
{
    // Выполняемый код
}
catch (System.Exception исключение)
{
    СоздатьОшибку("Возникла ошибка при согласовании отпуска", исключение);
}
```

`СоздатьПредупреждение(сообщение[, имя или Guid состояния типа 'Исключение', дата выполнения])`
- создает предупреждение с заданным сообщением, датой выполнения и с возможностью перехода в указанное состояние типа «Исключение». Предупреждение не прерывает бизнес-процесс

```csharp
СоздатьПредупреждение("Внимание!", датаВыполнения:System.DateTime.Now.AddMinutes(5));
```

`СоздатьПредупреждение(сообщение, исключение[, имя или Guid состояния типа 'Исключение', дата выполнения])`
- создает предупреждение с заданным сообщением, исключением, датой выполнения и с возможностью перехода в указанное состояние типа «Исключение». Предупреждение не прерывает бизнес-процесс

`Процесс.Наименование`
- возвращает наименование процесса

```csharp
string наименованиеПроцесса = ТекущийПроцесс.Наименование;
```

`Процесс.Прервать()`
- прерывает работу процесса

```csharp
ТекущийПроцесс.Прервать();
```

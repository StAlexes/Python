Стадия описывает состояние объекта, связанное с правами доступа пользователей на его просмотр и редактирование

Изменение стадии объектов

```csharp
using System;
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.Stages;

public class Macro(MacroContext context) : MacroProvider(context)
{
    public override void Run()
    {
        var selectedObjects = Context.GetSelectedObjects(); // Для примера изменим стадию у выбранных объектов

        if (selectedObjects.Length == 0)
            return;

        if (!selectedObjects[0].Reference.ParameterGroup.SupportsStages) // Определяем, поддерживает ли справочник механизм стадий
            return;

        Stage stage = Stage.Find(Context.Connection, Guid.Empty); // Находим стадию по Guid'у.
        // Поиск стадии по имени: Stage stage = Stage.Find(Context.Connection, "Разработка");

        stage?.Change(selectedObjects, "Комментарий к изменению стадии"); //  Изменяем стадию (если такой переход допустим по схеме)
        //stage?.Set(selectedObjects); // Изменяем стадию, игнорируя схему переходов. Если пользователь не является администратором, стадия устанавливается только у объектов, у которых она не задана
    }
}
```

Ссылки:

`TFlex.DOCs.Model.StagesStage`

> Внимание При изменении стадии переводить объекты в режим редактирования не нужно

Получение стадий, допустимых для объектов заданного справочника

```csharp
using System;
using System.Collections.Generic;
using TFlex.DOCs.Model;
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.Stages;

public class Macro(MacroContext context) : MacroProvider(context)
{
    public override void Run()
    {
        // Находим описание справочника по его Guid'у
        ReferenceInfo referenceInfo = Context.Connection.ReferenceCatalog.Find(Guid.Empty);
        // Если имеется экземпляр справочника, то получить его описание можно следующим образом:
        // ReferenceInfo referenceInfo = Context.Reference.ParameterGroup.ReferenceInfo;

        if (referenceInfo is null)
            return;

        // Получаем стадии справочника по его описанию
        List<Stage> referenceStages = Stage.GetStages(referenceInfo);
    }
}
```

Получение всех стадий в системе

```csharp
using System.Collections.Generic;
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.Stages;

public class Macro(MacroContext context) : MacroProvider(context)
{
    public override void Run()
    {
        List<Stage> allStages = Stage.GetStages(Context.Connection); // Получаем все стадии в системе
    }
}
```

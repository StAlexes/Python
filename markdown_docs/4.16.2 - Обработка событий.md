Если действие в системе направлено на объект или подключение в целом, то для обработки события достаточно информации о текущем объекте или подключении, которую можно получить из контекста выполнения макроса
MacroContext :

```csharp
ReferenceObject currentObject = Context.ReferenceObject; // Получаем текущий объект
ComplexHierarchyLink hierarchyLink = Context.HierarchyLink; // Получаем текущее подключение
```

К таким события относятся: «Удаление объекта», «Создание объекта», «Сохранение объекта», «Завершение сохранения объекта», «Создание подключения», «Удаление подключения».

Для ряда событий контекст выполнения макроса предоставляет возможность получения аргументов событий через свойство
ModelChangedArgs .

Аргументы событий позволяют получить данные, связанные с инициированными событиями.

```csharp
ModelEventArgs modelEventArgs = Context.ModelChangedArgs; // Получаем аргументы события изменения в модели
```

Класс ModelEventArgs является базовым типом для всех классов аргументов событий.
В зависимости от обрабатываемого события необходимо привести свойство ModelChangedArgs к нужному типу для получения аргументов.

Аргументы событий «Изменение параметра объекта» и «Завершение изменения параметра объекта»

ObjectParameterChangingEventArgs
- аргументы события изменения параметра объекта справочника

ObjectParameterChangedEventArgs
- аргументы события завершения изменения параметра объекта справочника

ObjectParameterChangedEventArgs и ObjectParameterChangingEventArgs предоставляют информацию об изменяемом параметре через свойство Parameter ,

и новое значение через свойство NewValue

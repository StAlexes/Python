В данном разделе описываются иерархические отношения между объектами справочников с типами иерархии объектов «Дерево» и «Сложная иерархия».
Иерархия формируется за счет подключения одних объектов к другим. В случае справочника со сложной иерархией объект может подключаться к нескольким родительским объектам.
В справочниках со сложной иерархией взаимодействие между объектами в иерархии выделено в отдельную сущность (объект) - 'Подключение' ,
что позволяет настраивать взаимодействие при помощи параметров.
Работа с подключениями описывается в разделе «Подключения» .
Для того чтобы получить конкретный родительский объект для выделенного объекта в справочнике со сложной иерархией, необходимо воспользоваться UI API - «Получение родительского объекта» .

`Объект.РодительскийОбъект`
- возвращает или устанавливает родителя объекта.
Если родительских объектов несколько (справочник со сложной иерархией), то вернет первого.
Родительский объект можно установить только для объекта справочника с простой иерархией (иерархия объектов "Дерево")

```csharp
var родительскийОбъект = ТекущийОбъект.РодительскийОбъект; // Получение родительского объекта
Объект папка = НайтиОбъект("Файлы", "Наименование", "Моя папка"); // Установка родительского объекта
ТекущийОбъект.РодительскийОбъект = папка;
ТекущийОбъект.Сохранить();
```

`Объект.РодительскиеОбъекты`
- возвращает список родителей объекта.
Список родительских объектов можно получить только для объекта справочника со сложной иерархией, в противном случае будет сгенерировано исключение

```csharp
var родительскиеОбъекты = ТекущийОбъект.РодительскиеОбъекты;
```

`Объект.ДочерниеОбъекты`
- возвращает список дочерних объектов

```csharp
var дочерниеОбъекты = ТекущийОбъект.ДочерниеОбъекты;
```

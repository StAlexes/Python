Логирование — это автоматическая запись информации о событиях, происходящих внутри программного обеспечения.
Макроязык позволяет добавлять информацию в специальный журнал ошибок (меню **«?»** > пункт **«Журнал ошибок...»**).

`ЗаписатьВЛогСообщение(сообщение, тип записи журнала)`
- записывает в «Журнал ошибок» сообщение с указанием типа

```csharp
ЗаписатьВЛогСообщение("Информация", ТипЗаписиЖурнала.Информационное);
ЗаписатьВЛогСообщение("Ошибка", ТипЗаписиЖурнала.Ошибка);
ЗаписатьВЛогСообщение("Предупреждение", ТипЗаписиЖурнала.Предупреждение);
```

`ЗаписатьВЛогТекст(текст)`
- записывает текст в «Журнал ошибок»

```csharp
ЗаписатьВЛогТекст("Обработка завершена");
```

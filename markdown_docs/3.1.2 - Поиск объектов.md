Поиск объектов и прототипов

`НайтиОбъект("(Имя справочника)", "(Имя параметра)", "(Значение параметра)")`
- выполняет поиск объекта в заданном справочнике по значению параметра. Возвращает объект или null, если объект не найден.

```csharp
Объект файл = НайтиОбъект("Файлы", "Наименование", "Мой документ.pdf");
if (файл is not null)
    ТекущийОбъект.СвязанныйОбъект["Файл"] = файл;
```

`НайтиОбъект("(Имя справочника)", "(Условие)")`
- выполняет поиск объекта в заданном справочнике по условию. Возвращает объект или null, если объект не найден.

```csharp
Объект макрос = НайтиОбъект("Макросы", "[Наименование] = Договоры");

if (макрос is not null)
{
    string result = макрос.Параметр["Комментарий"];
    Сообщение("Сообщение", "Комментарий макроса: {0}", result);
}
```

`НайтиОбъекты("Имя справочника", "Имя параметра", "Значение параметра")`
- выполняет поиск объектов в заданном справочнике по значению параметра. Возвращает список объектов.

```csharp
Объекты сборочныеЧертежи = НайтиОбъекты("Документы", "Наименование", "Сборочный чертёж");

foreach (Объект чертеж in сборочныеЧертежи)
{
    // ...
}
```

`НайтиОбъекты("(Имя справочника)", "(Условие)")`
- выполняет поиск объектов в заданном справочнике по условию. Возвращает список объектов.

`Условие(параметр, оператор[, значение])`
- условие для формирования фильтра справочника.

```csharp
Объекты сотрудники = НайтиОбъекты("Группы и пользователи", Условие("[Руководитель]->[Тип]", "!=", "Администратор"));
Объекты сотрудникиБезРуководителя = НайтиОбъекты("Группы и пользователи", Условие("[Руководитель]", "не содержит данных"));
string[] типы = ["Сотрудник", "Администратор"];
Объекты пользователи = НайтиОбъекты("Группы и пользователи", Условие("[Тип]", "Входит в список", типы));
```

`НайтиПрототип("(Имя справочника)", "(Условие)")`
- выполняет поиск прототипа в заданном справочнике по условию. Возвращает прототип или null, если прототип не найден.

```csharp
Объект прототип = НайтиПрототип("Документы", "[Тип] = 'Деталь'");
```

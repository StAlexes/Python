Команды для вывода сообщений.

`Сообщение("Заголовок", "Текст сообщения"[, параметры])`
- выводит сообщение с указанным заголовком и текстом.

```csharp
if (ТекущийОбъект.Параметр["Обозначение"] == "")
    Сообщение("Предупреждение.", "Не задано обозначение детали {0}", ТекущийОбъект.Параметр["Наименование"]);
```

`Ошибка("Сообщение об ошибке")`
- прерывает выполнение макроса и выводит указанное сообщение.

```csharp
if (ТекущийОбъект.Параметр["Обозначение"] == "")
    Ошибка("Не задано обозначение детали!");
```

`Вопрос("Текст вопроса")`
- показывает сообщение с текстом вопроса и вариантами Да/Нет

```csharp
if (Вопрос("Продолжить операцию?"))
    // Выполнение операции
else
    return;
```

`ВопросСОтменой("Текст вопроса")`
- показывает сообщение с текстом вопроса и вариантами Да/Нет/Отмена

```csharp
bool? результат = ВопросСОтменой("Уведомить ответственного при сохранении изменений?");

if (результат is null)
    Сообщение("Результат", "Отмена изменений");
else if (результат is true)
    Сообщение("Результат", "Сохранение изменений с уведомлением ответственного");
else
    Сообщение("Результат", "Сохранение изменений без уведомления ответственного");
```

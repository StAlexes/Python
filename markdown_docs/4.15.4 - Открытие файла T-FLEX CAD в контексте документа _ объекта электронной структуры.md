В данном примере рассмотрена возможность открытия документа CAD-системы в контексте документа или объекта электронной структуры

```csharp
using System;
using System.Linq;
using TFlex.DOCs.Model.FilePreview.CADService;
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.References.Documents;
using TFlex.DOCs.Model.References.Files;
using TFlex.DOCs.Model.References.Nomenclature;

public class OpeningFileInDocumentContext(MacroContext context) : MacroProvider(context)
{
    public override void Run()
    {
        var currentNomenclature = Context.ReferenceObject as NomenclatureObject; // Проверяем, является ли текущий объект объектом справочника "Электронная структура изделий"
        var document = currentNomenclature?.LinkedObject as EngineeringDocumentObject; // Проверяем, является ли связанный объект объектом справочника "Документы"
        var file = document?.GetFiles()
            .FirstOrDefault(f => f.Class.Extension.Equals("grb", StringComparison.OrdinalIgnoreCase)); // Находим связанный с документом grb-файл

        if (file is null)
            return;

        file.GetHeadRevision(); // Загружаем последнюю версию файла
        FileObject.SetOpenningDocumentId(file.LocalPath, document.SystemFields.Id, document.Reference.Id); // Задаем объект, в контексте которого будет открыт файл
        CadDocumentProvider provider = CadDocumentProvider.Connect(Context.Connection, ".grb"); // Подключаемся к CAD-системе

        using CadDocument cadDocument = provider.OpenDocument(file.LocalPath, true); // Открываем документ в режиме чтения
    }
}
```

Список объектов является аналогом связи внутри объекта.
Работа со объектами списка во многом схожа с работой с объектами справочника.
Отличительной особенностью является тот факт, что объект списка не представляет собой самостоятельный элемент и
его использование имеет смысл только в отношении объекта, внутри которого он был создан (объект-владелец).
В связи с этим, объект списка создается исключительно от объекта-владельца, редактируется и удаляется в рамках изменения объекта-владельца

Порядок операций при создании/редактировании объекта списка:

- Создание объекта-владельца или взятие на редактирование

  - Создание объекта списка или взятие на редактирование

  - Редактирование параметров и/или связей объекта списка

  - Сохранение объекта списка или отмена изменений
- Сохранение объекта-владельца или отмена изменений

При удалении порядок операций аналогичный:

- Создание объекта-владельца или взятие на редактирование

  - Удаление объекта списка (объект списка не должен находиться в режиме редактирования)
- Сохранение объекта-владельца или отмена изменений

Код по редактированию и сохранению объектов списка аналогичен коду для объектов справочника, подробности в соответствующем разделе

`Объект.СоздатьОбъектСписка("(Имя списка объектов)", "(Имя типа объекта)")`
- создает объект списка для текущего объекта (владельца).

```csharp
ТекущийОбъект.Изменить();

Объект новыйЭлемент = ТекущийОбъект.СоздатьОбъектСписка("Химический состав", "Элемент химического состава");
новыйЭлемент.Параметр["Химический элемент"] = 26; // Fe
новыйЭлемент.Сохранить();

ТекущийОбъект.Сохранить();
```

> Внимание Идентификатор (Id) созданного объекта списка равен нулю до сохранения объекта-владельца

`Объект.СвязанныеОбъекты`
`["(Имя или Guid списка объектов)"]`
- возвращает объекты списка.

```csharp
ТекущийОбъект.Изменить();
Объекты комментарии = ТекущийОбъект.СвязанныеОбъекты["Комментарии"];

foreach (Объект комментарий in комментарии)
{
    // Обработка объекта списка
}

ТекущийОбъект.Сохранить();
```

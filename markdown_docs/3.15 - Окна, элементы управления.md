Команды для работы с окнами

`ОткрытьОкноСправочника(справочник[, фильтр, корневой объект, вид, папка каталога])`
- открывает окно справочника

```csharp
var сборочнаяЕдиница = НайтиОбъект("Документы", "[ID] = '1'"); // Находим корневой объект

if (сборочнаяЕдиница is null)
    return;

ОткрытьОкноСправочника("Документы", "Тип = 'Деталь'", сборочнаяЕдиница, "Для классификатора"); // Открываем справочник с заданным фильтром, корневым объектом и видом
```

`ОткрытьОкноПросмотра(файл)`
- открывает окно просмотра с указанным файлом

```csharp
var файл = НайтиОбъект("Файлы", "Относительный путь", "Изображения\\TopSystems.png"); // Находим файл

if (файл is not null)
    ОткрытьОкноПросмотра(файл); // Открываем окно просмотра с указанным файлом
```

`ОткрытьРабочуюСтраницу(наименование или Guid РС)`
- открывает рабочую страницу

```csharp
ОткрытьРабочуюСтраницу("АРМ Технолога");
```

`УправлениеПроектами.ОткрытьРедакторПроектов(проекты[, вид, стиль])`
- открывает редактор проектов с возможностью указания вида и стиля

```csharp
Объекты проекты = НайтиОбъекты("Управление проектами", Условие("ID", "Входит в список", new int[] { 1, 3 }));

if (проекты.Count > 0)
    УправлениеПроектами.ОткрытьРедакторПроектов(проекты, "Основной", "Стиль 1");
```

`УправлениеПроектами.ОткрытьИспользованиеРабот(проект[, вид, стиль])`
- открывает окно использования работ проекта с возможностью указания вида и стиля

```csharp
Объект проект = НайтиОбъект("Управление проектами", Условие("ID", "=", 1));

if (проект is not null)
    УправлениеПроектами.ОткрытьИспользованиеРабот(проект, "Основной", "Стиль 1");
```

`УправлениеПроектами.ОткрытьИспользованиеРесурсов([проекты, ресурс, вид, стиль])`
- открывает окно использования ресурсов с возможностью указания конкретного ресурса/проекта, вида и стиля

```csharp
Объект проект = НайтиОбъект("Управление проектами", Условие("ID", "=", 1));
Объект ресурс = проект?.СвязанныеОбъекты["Ресурс"].FirstOrDefault();

if (ресурс is not null)
    УправлениеПроектами.ОткрытьИспользованиеРесурсов(null, ресурс, "Основной", "Стиль 1");

// Передаваемые в метод ресурс и проект являются взаимоисключающими.
// Можно передать в метод проект, тогда ресурс будет проигнорирован. Пример с проектом:
// if (проект is not null)
//    УправлениеПроектами.ОткрытьИспользованиеРесурсов(проект, null, "Основной", "Стиль 1");
```

`ОбновитьОкноСправочника()`
- обновляет окно текущего справочника

```csharp
var деталь = СоздатьОбъект("Документы", "Деталь"); // Создаем объект в справочнике "Документы"
деталь["Наименование"] = "тестовая деталь";
деталь["Обозначение"] = "Д1";
деталь.Сохранить();

ОбновитьОкноСправочника(); // Обновляем окно справочника
```

ТекущееОкно
- возвращает текущее окно (в контексте которого выполняется макрос). Например, диалог свойств или рабочая страница

`Окно.Обновить()`
- обновляет данные окна

`Окно.ОбновитьЭлементУправления(наименование ЭУ)`
- обновляет элемент управления

`Окно.Наименование`
- возвращает наименование окна

`Окно.НайтиЭлементУправления(наименование ЭУ)`
- выполняет поиск элемента управления в окне по наименованию. Возвращает ЭУ или null, если ЭУ не найден

Команды для работы с элементами управления

`ЭлементУправления.Наименование`
- возвращает наименование ЭУ

`ЭлементУправления.ВыбранныеОбъекты`
- возвращает выбранные в ЭУ объекты

`ЭлементУправления.ВыбранныеПодключения`
- возвращает выбранные в ЭУ подключения

`ЭлементУправления.Обновить()`
- обновляет данные ЭУ

`ЭлементУправления.ПоддерживаетВиды`
- возвращает значение, указывающее, поддерживает ли элемент управления работу с видами

`ЭлементУправления.ПолучитьВиды()`
- возвращает доступные виды для ЭУ

`ЭлементУправления.ПолучитьТекущийВид()`
- возвращает текущий вид ЭУ

`ЭлементУправления.ПрименитьВид(Guid вида)`

`ЭлементУправления.ПрименитьВид(наименование вида)`

`ЭлементУправления.ПрименитьВид((наименование, Guid) вид)`

- применяет вид к ЭУ

`ЭлементУправления.ПоддерживаетФильтрацию`
- возвращает значение, указывающее, поддерживает ли элемент управления работу с фильтрами

`ЭлементУправления.УстановитьТекущийФильтр(условия)`

`ЭлементУправления.УстановитьТекущийФильтр(условие)`

`ЭлементУправления.УстановитьТекущийФильтр(объект справочника 'Поисковые запросы')`

`ЭлементУправления.УстановитьТекущийФильтр(параметр, значение)`

`ЭлементУправления.УстановитьТекущийФильтр(фильтр)`

`ЭлементУправления.УстановитьТекущийФильтр(Guid объекта справочника 'Поисковые запросы')`

- устанавливает текущий фильтр

`ЭлементУправления.ВключитьФильтр()`

`ЭлементУправления.ОтключитьФильтр()`

- включает или отключает фильтр (программный вызов команды "Найти")

Пример работы с окнами и элементами управления

```csharp
using TFlex.DOCs.Model.Macros;
using TFlex.DOCs.Model.Macros.ObjectModel;
using TFlex.DOCs.Model.Macros.ObjectModel.Layout; // Для работы с окнами и ЭУ необходимо подключить данное пространство

public class Macro : MacroProvider
{
    public Macro(MacroContext context)
        : base(context)
    {
    }

    public override void Run()
    {
        Окно текущееОкно = ТекущееОкно; // Получаем текущее окно
        if (текущееОкно == null)
            return;

        текущееОкно.Обновить(); // Обновляем данные в текущем окне
        string наименованиеОкна = текущееОкно.Наименование;

        ЭлементУправления эу = текущееОкно.НайтиЭлементУправления("item1"); // Находим определенный ЭУ по имени
        if (эу != null)
        {
            эу.Обновить(); // Обновляем данные ЭУ
            string наименованиеЭУ = эу.Наименование;
            Объекты выбранныеОбъекты = эу.ВыбранныеОбъекты; // Если ЭУ содержит объекты, то получаем выбранные
        }
    }
}
```
